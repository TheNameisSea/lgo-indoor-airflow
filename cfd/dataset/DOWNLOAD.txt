Indoor CFD dataset -- put it here.

Download:  Zenodo 10.5281/zenodo.22955315

    wget https://zenodo.org/records/22955315/files/indoor_cfd_dataset.tar.gz
    tar -xzf indoor_cfd_dataset.tar.gz -C cfd/dataset/

Extract so that every case is a directory directly under this one:

    cfd/dataset/B000/Fluid_data.csv
    cfd/dataset/B000/New_HVAC.csv
    cfd/dataset/B000/...            21 CSVs per case, 193 cases

Then build the split trees: REPRODUCING.md, step 2.
To generate the data yourself instead: REPRODUCING.md, step 8.
